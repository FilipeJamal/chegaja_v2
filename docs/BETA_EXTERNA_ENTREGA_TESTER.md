## Objetivo

Este documento existe para registar a primeira entrega real da beta do ChegaJa
a uma pessoa humana fora do fluxo de desenvolvimento.

A beta solo assistida por Playwright validou tecnicamente os fluxos principais,
mas nao substitui a validacao humana.

## Criterio para Fechar R1

R1 so pode ser marcado como fechado quando:

```text
1. tester humano recebeu o link/pacote;
2. plataforma entregue foi registada;
3. data/hora de envio foi registada;
4. tester confirmou recebimento ou acesso;
5. documentos de instrucao e feedback foram enviados;
6. o registo de entrega foi atualizado com evidencia.
```
