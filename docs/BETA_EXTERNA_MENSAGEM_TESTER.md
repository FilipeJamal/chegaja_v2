# Beta Externa - Mensagem para Tester

Data: 2026-05-23

## Objetivo

Mensagem pronta para enviar ao tester quando a entrega real for feita.

## Mensagem Curta

```text
Ola.

Estou a enviar uma beta do ChegaJa para teste em Web/Windows.

Objetivo do teste:
- abrir a app;
- testar como Cliente;
- testar como Prestador;
- criar e acompanhar um pedido;
- testar mensagens;
- testar conta/perfil;
- reportar qualquer bug com screenshot ou video, se possivel.

Antes de comecar, abre estes ficheiros:
1. BETA_TESTER_GUIA_RAPIDO.md
2. BETA_TESTER_ROTEIRO_SIMPLIFICADO.md
3. BETA_TESTER_FEEDBACK_FORM.md
4. BETA_TESTER_BUG_REPORT.md

Limites desta beta:
- nao testar pagamentos reais;
- nao testar Play Store;
- nao testar Android fisico;
- nao testar funcionalidades fora do roteiro.

Se encontrares bug, regista:
- o que fizeste;
- o que esperavas;
- o que aconteceu;
- se aconteceu sempre ou so uma vez;
- screenshot/video, se houver.
```

## Instrucao de Entrega

Quando a app for entregue ao tester, preencher:

```text
docs/BETA_EXTERNA_REGISTO_ENTREGA.md
```

Depois da execucao do roteiro, preencher:

```text
docs/BETA_EXTERNA_BUGS_REPORTADOS.md
docs/BETA_EXTERNA_DECISAO.md
```
