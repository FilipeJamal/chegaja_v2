# Checklist de funcionalidade UI — ChegaJá

Antes de pedir ao Codex para implementar:

- [ ] Qual tela será alterada?
- [ ] Cliente, Prestador ou ambos?
- [ ] O que o utilizador deve conseguir fazer?
- [ ] Qual estado inicial?
- [ ] Qual estado final?
- [ ] Quais estados de erro?
- [ ] Há screenshot/referência?
- [ ] Há dados mockados ou reais?
- [ ] Que ficheiros são prováveis?
- [ ] O que é proibido mexer?

Depois de implementar:

- [ ] Testado em desktop.
- [ ] Testado em mobile/responsivo.
- [ ] Testado com dados vazios.
- [ ] Testado com dados reais/mockados.
- [ ] Testado com texto longo.
- [ ] Loading aparece bem.
- [ ] Erro aparece bem.
- [ ] Não quebrou fluxo antigo.
- [ ] `flutter test --no-pub` passou.
- [ ] Commit feito.
