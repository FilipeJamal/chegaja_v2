# Prompt — Reproduzir bug antes de corrigir

```txt
Antes de corrigir, quero que reproduzas o bug.

Bug:
[descrever]

Passos que fiz:
[passos]

Resultado atual:
[o que aconteceu]

Resultado esperado:
[o que devia acontecer]

Tarefa:
1. Identifica ficheiros prováveis.
2. Explica hipótese da causa.
3. Cria plano curto.
4. Corrige com a menor alteração possível.
5. Adiciona/atualiza teste se fizer sentido.
6. Executa testes.
7. Explica como testar manualmente.

Regras:
- Não fazer alterações grandes.
- Não mexer em áreas não relacionadas.
- Não fazer commit se os testes falharem.
```
