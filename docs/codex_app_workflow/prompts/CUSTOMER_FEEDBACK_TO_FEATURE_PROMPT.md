# Prompt — Transformar feedback real em funcionalidade

```txt
Tenho este feedback de utilizador/cliente:

[colar feedback]

Quero que transformes isto em uma melhoria concreta para o ChegaJá.

Faz:
1. Interpreta a dor real do utilizador.
2. Diz se é bug, melhoria UX, nova funcionalidade ou texto/copy.
3. Propõe MVP pequeno.
4. Propõe versão futura mais completa.
5. Lista riscos.
6. Lista ficheiros prováveis.
7. Define critérios de aceite.
8. Define testes manuais e automatizados.
9. Não implementes ainda até o plano estar claro.

Contexto do ChegaJá:
- app Flutter + Firebase;
- fluxos Cliente/Prestador;
- pedidos imediato/agendado/orçamento;
- foco em produto real, não só código.
```
